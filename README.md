# RK4-CONCEPT

A Python implementation of the classical fourth-order Runge-Kutta (RK4) method
for solving the differential equation `dy/dt = y`, with a plot comparing the
numerical result to the exact solution.

## Run

Install the required packages:

```bash
python -m pip install numpy matplotlib
```

Then run:

```bash
python RK41.PY
```

The script saves the plot as `RK41_result.png` in the current directory.
